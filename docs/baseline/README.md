# 正式基線文件

本目錄只保存目前有效、可供工程實作引用的正式基線：

1. `產品研究與要件手冊_v1.2.md`：定義產品目的、範圍、需求、非功能需求與驗收標準。
2. `基本設計書_v1.1.md`：定義 §24～§28 的系統邊界、角色、流程狀態、資料模型、模組架構與畫面操作。

矛盾時依 `../GOVERNANCE.md` 的權威順序判斷。CR、稽核報告與歷史版本不放入本目錄，也不得取代上述正式基線。

Markdown 是工程引用來源。排版用 PDF 保留在原交付包，不納入程式 repository，以免重複保存大型二進位檔；兩份 Markdown 已與原交付包逐檔 SHA-256 核對一致。
