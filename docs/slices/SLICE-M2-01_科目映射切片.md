**基線對應**：REQ-MAP-001／AC-MAP-001（手冊 §13/§19）、G-02（設計書 §25.13）、
MappingRule（§26.8）、B-04（§28.5）、§24.1A 歸屬完整性、MVP 1 離開條件

## 驗收清單

| # | 條件 | 驗證位置 |
|---|---|---|
| 1 | 映射可建立（草稿）、由**另一自然人**（R4）批准後生效；批准人 ≠ 建立者（實例級，DB 觸發器最後防線） | DB 整合＋端到端 |
| 2 | 已批准映射版本不可 UPDATE／DELETE；變更＝插入新 version_no；同 (案件, 來源科目, 版本) 唯一 | DB 整合 |
| 3 | 目標科目必須屬於同一 Tenant × 案件的科目表；跨案件指向被 DB 觸發器與 API 雙層拒絕並記錄違規（§24.1A） | DB 整合＋端到端 |
| 4 | 跨 Tenant 不可見／不可寫（mapping_rule 在 RLS 政策內） | DB 整合 |
| 5 | 對 ACCEPTED 批次自動套用**目前生效**映射（每來源科目取最高已批准版本），多對一正確加總 | 單元＋端到端 |
| 6 | 未映射科目逐一列出，含影響金額（借＋貸）；映射覆蓋率（按金額）可見 | 單元＋B-04 畫面 |

| 8 | 集團 TB 預覽頁標示 PREVIEW、非正式輸出；來源 TB 與集團 TB（含未映射桶）借貸控制總額勾稽一致 | 端到端 |
| 9 | **Case-001 比對**：2026-03 期集團 TB 與 `expected_group_tb_2026-03.csv` 逐科目（12/12）金額完全一致 | 端到端 |
