## 三個已知缺口（聚焦）

1. **UNVERIFIABLE 人工確認 UI**：DB 防線完備（SOD-07、不可覆寫、批次版本效力），
   但使用者流程是死路——判定**阻擋**（AC-CTX-001 最低覆蓋義務）。
2. **期間狀態機**：G-02 掛在替代動作、G-10／鎖定／期初銜接不存在——判定**阻擋**
   （REQ-PER-001／WFL-001 鎖定條款）。
3. **B-00 待辦整合**：等我處理的事項（含待身分確認佇列——B-00 規格 P0 明列）、
   未完成草稿、一鍵回位——判定**阻擋**（MVP 2 離開條件第三句）。

## 結論與下一刀

**里程碑 2 尚不能宣告離開。**阻擋清單（依修復順序）：

1. **B-00 待辦整合 ＋ UNVERIFIABLE 人工確認 UI（合併為一刀）**——兩者天然同體：
   B-00 規格 P0 的「等我處理的事項」明列**待身分確認佇列**，佇列的點擊目的地就是
   確認畫面（SOD-07 已有 DB 防線，UI 薄）。此刀同時解掉盤點中的流程死路與
   MVP 2 離開條件第三句，且不新增任何控制語意——風險最低、收益最大。
2. **期間狀態機最小刀**（OPEN→LOCKED＋G-10 期初銜接＋重開 revision）——REQ-PER-001／
   WFL-001 的阻擋項；G-02 順勢掛回正式遷移。
3. **多基礎最小資料模型**（BookBasis／PostingLayer／四類規則落表，不做規則引擎）——
   REQ-BAS-001／RUL-001 的阻擋項；折算（MVP 3）與遞延稅的前置。
4. 之後才是：稅理士批准與正式交付、折算 MVP 3（與使用者預判一致——
   折算不是下一刀，流程缺口優先）。
